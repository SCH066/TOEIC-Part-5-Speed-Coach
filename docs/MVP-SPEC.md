# MVP-SPEC.md — 可測驗收規格
版本: 1.0.0
日期: 2026-02-03

> 本文件定義 TOEIC Part 5 Speed Coach 的功能驗收條件（AC）與 Smoke Tests。

---

## 1) Legacy Features 驗收條件（現有功能）

### [L-01] Onboarding 流程
**AC：**
- [ ] 首次開啟顯示 Onboarding 頁面
- [ ] 必須填寫目標分數、最近成績才能開始
- [ ] 可選擇弱點領域（時態/介系詞/連接詞/詞性/字彙/全部）
- [ ] 設定完成後導向 Dashboard

### [L-02] Dashboard 總覽
**AC：**
- [ ] 顯示歡迎訊息與專注領域
- [ ] 顯示平均速度（秒）
- [ ] 顯示正確率（%）
- [ ] 顯示已完成測驗數
- [ ] 顯示今日待複習數（SRS 到期題目）
- [ ] 顯示收藏單字數

### [L-03] Quiz 測驗系統
**AC：**
- [ ] 每輪顯示題目進度（第 N/M 題）
- [ ] 顯示即時計時器
- [ ] 點擊選項後立即顯示對錯回饋
- [ ] 顯示全選項 A/B/C/D 分析
- [ ] 顯示題目標籤（題型分類）
- [ ] 答題記錄寫入 quizHistory

### [L-04] 錯題本 (Mistake Book)
**AC：**
- [ ] 顯示所有錯題列表
- [ ] 支援標籤過濾（依題型篩選）
- [ ] 每題顯示：題目、您的答案、正確答案、分析
- [ ] 顯示 SRS 狀態（下次複習日期、間隔天數）

### [L-05] SRS 演算法
**AC：**
- [ ] 答錯的題目加入錯題本
- [ ] 答對快速（grade=5）：間隔拉長
- [ ] 答對緩慢（grade=3）：間隔適度增加
- [ ] 答錯（grade=0）：間隔重置為 1 天
- [ ] 複習隊列優先抽取到期題目

### [L-06] 單字庫 (Word Bank)
**AC：**
- [ ] 測驗回饋頁面顯示 Smart Vocab 推薦
- [ ] 點擊 Chip 可一鍵收藏
- [ ] 已收藏的單字顯示不同樣式
- [ ] 單字庫頁面以 Flip Card 呈現
- [ ] 點擊卡片可翻轉查看定義與例句

### [L-07] 資料管理
**AC：**
- [ ] 匯出 CSV：包含答題記錄
- [ ] 匯出 JSON：完整備份所有資料
- [ ] 匯入 JSON：還原備份資料
- [ ] 重置功能：清除所有資料並返回 Onboarding

## 2) Sprint 1 新功能驗收條件

### [F-01] 抽題演算法優化
**AC：**
- [ ] 同一題在連續 N 輪內不重複出現（建議 N=3）
- [ ] 同一題型在同一輪內最多出現 M 題（建議 M=3）
- [ ] 冷卻機制不影響 SRS 到期題目的優先抽取

**Smoke Test：**
1. 連續進行 3 輪測驗
2. 記錄每輪出現的題目 ID
3. 驗證同一題未在連續輪次中重複

### [F-02] 資料安全強化
**AC：**
- [ ] localStorage 讀取失敗時顯示友善錯誤訊息
- [ ] localStorage 寫入失敗時顯示警告並不崩潰
- [ ] 資料載入時驗證必要欄位存在
- [ ] 損壞資料不影響其他正常資料

**Smoke Test：**
1. 手動在 DevTools 破壞 localStorage 資料
2. 重新載入頁面
3. 驗證應用程式不崩潰，顯示適當錯誤處理

### [E-01] 題數彈性化
**AC：**
- [ ] Dashboard 或測驗開始前可選擇題數
- [ ] 提供選項：3 題 / 5 題 / 10 題
- [ ] 測驗進度正確顯示（第 N/選擇的總題數）
- [ ] 結果頁面正確計算正確率

**Smoke Test：**
1. 選擇 3 題模式
2. 完成測驗
3. 驗證只出現 3 題，結果頁顯示 X/3

### [E-02] 題庫擴充
**AC：**
- [ ] 題庫數量 >= 50 題
- [ ] 新題目包含完整欄位：text, options, correctIndex, tags, vocab, analysis
- [ ] 題型分佈均衡（每類至少 8 題）

**Smoke Test：**
1. 檢查 questions.js 題目數量
2. 驗證每題結構完整
3. 統計各題型數量

### [E-03] PWA 基礎建設
**AC：**
- [ ] 存在 manifest.json 並正確連結
- [ ] 定義 App 名稱、圖示、主題色
- [ ] 存在 service-worker.js
- [ ] 可加到手機主畫面
- [ ] 主畫面開啟時為獨立視窗（standalone）

**Smoke Test：**
1. 手機瀏覽器開啟網站
2. 選擇「加到主畫面」
3. 從主畫面開啟，驗證為獨立 App 樣式

### [D-01] README 更新
**AC：**
- [ ] 專案描述清楚說明產品用途
- [ ] 包含正確的 Live Demo 連結
- [ ] 包含本地執行說明
- [ ] 包含功能特色列表
- [ ] 版本號更新為 v1.4.0

### [D-02] LICENSE 確認
**AC：**
- [ ] LICENSE 檔案存在
- [ ] 內容為 MIT License
- [ ] 年份與作者正確

### [D-03] CHANGELOG 更新
**AC：**
- [ ] 新增 v1.4.0 版本區塊
- [ ] 記錄所有新功能與修復
- [ ] 格式遵循 Keep a Changelog 規範

| 10 | 連續 3 輪測驗 | 同一題不重複出現 |
